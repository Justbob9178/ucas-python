1. Coordinates and independent rows

Think of a small woodland divided into cells. A 2D list is a list of rows; a location is found by world[row][column]. Row 0 is the top row and column 0 the left column.

States are 0 empty, 1 tree, 2 burning and 3 fireproof or burned. Click a cell to cycle through these states. Compare its coordinates with the display.

Why independent rows matter

If every row points to the same list, changing one position appears to change every row. Use the lab to compare those two designs.

Both demonstrations start with three rows of zeros, then change row 0, column 1.

2. Neighbours and boundaries

Our model uses only the cells immediately above, below, left and right. These are orthogonal neighbours. Diagonals do not count and edges do not wrap.

Select a cell; the lab highlights its existing neighbours. Predict the count first: a corner has 2, an ordinary edge 3 and an interior cell 4.

Watch out: Python negative indices are valid list accesses. A calculation of row −1 must be rejected here, or the model could accidentally connect the top to the bottom.

3. Old state and new state

A simultaneous update decides the whole next turn from the same old snapshot. Newly burning trees wait until the next turn before spreading. If you write and read the same row during the scan, fire can wrongly leap across the row in one turn.

This lab uses 100% spread and no burnout to isolate that rule. Predict the first next state of burning, tree, tree, tree, empty.

New state

Two sources, one new case: in burning–tree–burning, both sources can attempt to ignite the middle tree. The tree still counts as one new burning location. Count successful target cells, not successful attempts.

4. Probabilities and repeatable trials

A 25% chance means each independent attempt succeeds when a random draw from 0 (inclusive) to 1 (exclusive) is below 0.25. It does not force one success in every four attempts. A seed sets the generator’s starting state so a fresh run can repeat its sequence.

Run twice with the same seed and chance. Then change only the seed.

Burnout order: old burning trees attempt spread first, then may burn out into state 3. With 100% spread and 100% burnout, burning–tree–tree becomes fireproof–burning–tree. The new fire does not burn out on that same turn.

This lab uses a simple seeded generator for teaching. Its sequence is not Python’s random generator sequence.

5. Current, peak and cumulative counts

Current means burning now. Peak is the largest current count seen so far, including the initial state. Cumulative counts distinct locations that have ever burned, including the initial fire. Because state 3 cannot burn again, you can add unique new fires each turn.

At a 25% outbreak threshold, 4 out of 10 occupied locations meets the threshold. Do not divide by the total grid size or the remaining susceptible trees.

6. Design a fair experiment

To compare firebreak coverage, run fresh worlds for each condition using the same recorded list of different seeds. Hold the world size, occupancy chance, spread chance, burnout chance and turn limit constant. Many turns of one world are not many independent trials.

To compare protective stations, keep the coverage setting fixed and use the same number of stations in the central and edge strategies. A target next to any station has its spread chance halved once. Two stations do not halve it twice.

Before the project: explain why old/new grids are necessary, predict boundary neighbours, distinguish peak from cumulative, and state which settings a fair comparison holds fixed. The project supplies different state labels and its own exact experiment requirements.
