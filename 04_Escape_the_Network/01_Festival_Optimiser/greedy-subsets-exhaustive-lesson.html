01 · Understand the problem

Choose activities you can actually attend

You are visiting a science convention from 12:00 to 15:00. Each activity has an interest score. Your aim is to get the highest total score from activities that do not overlap.

Compatibility rule: two activities can meet exactly at an endpoint. An activity ending at 13:00 is compatible with one starting at 13:00. Travel time is ignored in this example.

What you will learn

  1. Greedy: take the highest-scoring remaining activity if it fits.
  2. Subsets: understand every possible selection of activities.
  3. Exhaustive search: check every selection and remember the best valid one.
  4. Compare: explain the difference between a quick choice and a guaranteed best score.

02 · Greedy simulation

Make the best-looking choice now

This greedy method considers activities from highest score to lowest. It accepts each activity only if it fits with all activities already accepted. It keeps earlier decisions. Equal scores use alphabetical ID order.

A compulsory favourite must be included: when one is selected, reserve it first, then consider the remaining activities in score order.

Changing the favourite resets the greedy and exhaustive traces. The same rule applies to both methods.

Why this can fail

One long activity can block two shorter activities whose scores add up to more. Greedy does not go back and replace its earlier choice.

03 · Subset explorer

A subset is a selection of items

For each activity, choose include or exclude. A subset can contain no activities, some activities or all activities. Order does not create a new subset: B then C and C then B are the same selection.

Four activities give 2 × 2 × 2 × 2 = 16 subsets. Some have clashes. Every valid timetable is one of these subsets, but not every subset is a valid timetable.

Why does the empty selection count?

It is the choice to exclude every activity. Its score is 0 and it has no time clashes. If a favourite is required, the empty selection fails that extra rule.

04 · Exhaustive search simulation

Try every selection and keep the best

Exhaustive search generates every subset. For each one, reject it if it clashes or misses the compulsory favourite. Otherwise, calculate its total score and compare it with the best valid score so far.

We check subsets in a fixed include/exclude order. This is an order for examining selections, not an activity ranking. Equal best scores keep the first valid selection found.

05 · Compare and transfer

Same input, different strategies

What guarantees the best score?

Exhaustive search guarantees the best valid score here because it checks every possible selection using the same clash and favourite rules. Greedy is a heuristic: a practical choice rule that does not guarantee the best result for this rating-based scheduling problem.

How fast do subsets grow?

Each additional activity doubles the possibilities. For 20 activities, checking every subset means 1,048,576 candidates, before considering the work needed to check each one.

A fair investigation

  • Use the same activities, ratings and favourite for both methods.
  • Record both score and work.
  • Label subset counts and overlap checks separately.
  • A greedy method can match the optimum on one input and lose on another.
